# 🏥 Hospital Appointment Management System

## 📌 About the Project
The Hospital Appointment Management System is a Java-based desktop application developed using Java Swing, MySQL, and JDBC. It helps manage hospital operations such as patient records, doctor details, and appointments through a simple graphical user interface.

## ✨ Features
- Patient Management
- Doctor Management
- Appointment Booking
- MySQL Database Connectivity
- User-Friendly Graphical Interface

## 🛠️ Technologies Used
- Java (JDK 17)
- Java Swing
- MySQL
- JDBC (MySQL Connector/J)
- Eclipse IDE
- MySQL Workbench

## ⚙️ Prerequisites
- JDK 17 or compatible version
- Eclipse IDE
- MySQL Server
- MySQL Connector/J driver

## 🚀 How to Run
1. Download or clone this repository.
2. Open Eclipse IDE and import the project.
3. Create the required database in MySQL.
4. Configure the database username, password, and connection URL.
5. Add MySQL Connector/J to the project build path.
6. Run `HospitalmanagementGUI.java` to launch the application.

## 🗄️ Database Configuration
- **Database:** `hospital`
- **Connection URL:** `jdbc:mysql://localhost:3306/hospital`
- **Username:** Your MySQL username
- **Password:** Your MySQL password

Create the required tables before running the application. Refer to the SQL scripts included in the repository, if available.

## 🎯 Objective
The main objective of this project is to simplify hospital record management and demonstrate the use of Java Swing, JDBC, and MySQL in desktop application development.
